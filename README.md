# ♻️ Re-Cycle Tech

## Plataforma de Gestión de Residuos Electrónicos y Trazabilidad de Economía Circular

---

## 📋 Descripción del Proyecto

**Re-Cycle Tech** es una plataforma web que conecta a ciudadanos con centros de acopio para gestionar residuos electrónicos (e-waste) de forma responsable y trazable. El sistema permite registrar dispositivos electrónicos en desuso, ubicar centros de acopio cercanos mediante geolocalización, y dar seguimiento a cada residuo desde su registro hasta su destino final (donación, reciclaje, reacondicionamiento o destrucción segura).

Este proyecto fue desarrollado como parte de la **Estancia Profesional** de la **ESIT (Escuela Superior de Innovación y Tecnología)** para la Agencia AARD (Agencia para el Aprovechamiento y Recirculación Responsable de Desechos Tecnológicos).

---

## 🎯 Objetivos del Proyecto

- ✅ Digitalizar la gestión de residuos electrónicos
- ✅ Conectar ciudadanos con centros de acopio cercanos
- ✅ Proporcionar trazabilidad completa de cada residuo
- ✅ Promover la economía circular y la responsabilidad ambiental
- ✅ Generar reportes y estadísticas para la toma de decisiones

---

## 🚀 Tecnologías Utilizadas

### Backend
- **Spring Boot** 3.2.0 – Framework para la API REST
- **Java** 17 – Lenguaje de programación
- **Spring Security** + **JWT** – Autenticación y autorización
- **Spring Data JPA** – Acceso a datos y ORM
- **PostgreSQL** – Base de datos relacional
- **Maven** – Gestión de dependencias
- **Docker** – Contenerización de la base de datos

### Frontend
- **React** 18 – Biblioteca para interfaces de usuario
- **Vite** – Herramienta de construcción rápida
- **Tailwind CSS** (opcional) – Estilos modernos
- **Axios** – Cliente HTTP para consumir la API
- **@react-google-maps/api** – Integración con Google Maps

### Documentación y Pruebas
- **Swagger/OpenAPI** – Documentación interactiva de la API
- **Postman** – Pruebas de endpoints

### Despliegue (Opcional)
- **Vercel** – Hosting del frontend
- **Render** – Hosting del backend
- **Neon.tech** – Hosting de PostgreSQL
